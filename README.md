# Homebrew Tap

Upstream Homebrew formulae for [SwiftUI Semantic Audit](https://github.com/potapenko/swiftui-semantic-audit).

## Install

```bash
brew install potapenko/tap/swiftui-semantic-audit
swiftui-audit --version
```

The formula installs the standalone `swiftui-audit` CLI. Agent skills remain a separate, explicit installation described by the upstream project.
